# Blocked PR buyer proof

Use this as the public/redacted proof packet before asking for payment or private access.

## What the buyer sends

- Public PR URL or a saved/redacted `git diff`.
- Exact failing command/check name or reviewer blocker.
- Redacted first error/log excerpt if CI is failing.
- Desired outcome: reproduce note, minimal patch, test update, reviewer-map note, or reviewer reply draft.

Do **not** send credentials, secrets, private repo exports, private customer data, private CI dashboard links, private logs, or requests for scraping/auto-commenting.

## What the free proof returns

1. Readiness verdict from the local diff only.
2. Top 3 risk findings.
3. Smallest reproducible command or missing input.
4. One likely fix path.
5. One rollback/reviewer note.

## Paid-pilot gate

Count as qualified pipeline only when the buyer provides usable public/redacted PR or diff inputs with an exact failing command/log/reviewer blocker, or explicitly says they want fixed-scope cleanup.

Payment links, invoices, new accounts, KYC, and payment collection stay on Corey hold until that explicit paid-pilot intent exists.

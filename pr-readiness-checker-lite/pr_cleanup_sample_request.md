# PR cleanup sample request template

Use this to convert “can you look at this PR?” interest into qualified, paste-safe inputs before any paid pilot.

## Paste-ready ask

> I can run a local PR readiness pass if you share only public/redacted inputs. Please send:
>
> 1. Public PR or repo URL, or a saved/redacted `git diff` if the repo is private.
> 2. The failing CI/test command, reviewer concern, or exact merge blocker.
> 3. What you want fixed: tests, reviewer map, smaller PR split, docs/release note, or risk notes.
> 4. Whether this is free-sample only, maybe-after-sample, or explicit paid fixed-scope cleanup interest.
>
> Boundaries: no credentials, private customer data, secrets, private repo login, scraping, auto-commenting, or guaranteed merge/payment claims. Payment collection stays on Corey hold until invoice/payment/account/KYC setup is approved after explicit buyer intent.

## Count as qualified pipeline

- public PR URL with a concrete blocker;
- redacted diff plus failing check/reviewer concern;
- explicit paid fixed-scope cleanup interest.

## Do not count

- stars, views, silence, generic “interesting”;
- requests for account login/private repo access/secrets;
- requests to scrape, auto-submit, auto-comment, or guarantee merge/payment;
- broad consulting asks with no concrete PR/diff.

## Kill/replace rule

If this public route produces 5 no-count outcomes and 0 qualified PR/diff inputs, stop polishing it and replace with a narrower buyer angle: “CI failure patch preflight” for maintainers with public failing checks.

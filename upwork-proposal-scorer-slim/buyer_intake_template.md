# Buyer intake template — proposal QA sample

Send this only after a warm/permissioned contact asks for a sample, a trial, or more detail. It converts interest into the minimum safe inputs needed for a useful no-login review.

## Copy/paste reply

> Great — send only paste-safe text, no account access or private client data:
>
> 1. One public job post or redacted job summary.
> 2. One draft proposal you are comfortable having scored locally.
> 3. Your niche: agency, coach, freelancer, or other.
> 4. One proof point you can truthfully cite.
> 5. Whether you want a sample score only or a custom $49 rubric pilot if the sample is useful.
>
> Boundaries: I will not log in, scrape, auto-submit, guarantee wins, handle payment details here, or ask for credentials.

## Count as qualified signal only if

- They send job/proposal text or ask for the sample output.
- They specify niche/proposal style.
- They ask about the $49 custom rubric pilot.

## Do not count

- Likes, generic “interesting,” silence, or requests for guaranteed wins / auto-submit / login access.

## Payment gate

If they ask to pay, stop before invoice/payment link/account setup and route Corey approval with the exact buyer, price, upside, downside, and what we learn if they decline.
